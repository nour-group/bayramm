# Security Policy

Please **do not open a public issue** for security problems.

Report privately via
[GitHub Security Advisories](https://github.com/nour-group/bayramm/security/advisories/new)
(“Report a vulnerability”). Include the affected URL or file, steps to reproduce and the impact.
We aim to acknowledge reports within 3 business days.

Please do not access, modify or delete data that isn't yours, do not degrade the service,
and do not run automated scanners against production.
